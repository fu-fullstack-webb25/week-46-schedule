# Schema, vecka 46
###### Fullstack webbapplikation med TypeScript, vecka 2 av 7

## Introduktion

Under kursens andra vecka fokuserar vi på webbsäkerhet och externa betallösningar. Vi går igenom hur cookies och sessions används för att hantera användare på ett säkert sätt, samt hur vi kan skydda våra webbapplikationer mot vanliga säkerhetshot med hjälp av bland annat Content Security Policy (CSP) och botskydd.

Vi kommer även att undersöka hur externa betallösningar, exempelvis Stripe, kan integreras i en fullstackapplikation. Genom praktiska exempel får du förståelse för hur frontend och backend samverkar för att hantera betalningar på ett säkert sätt.

Veckan avslutas med en introduktion till det kommande grupprojektet, där vi går igenom projektets krav, agila arbetssätt och förberedelser inför utvecklingsarbetet.


## Mål för veckan:

1. Förstå och använda cookies och sessions.
2. Identifiera vanliga säkerhetsrisker i webbapplikationer.
3. Tillämpa grundläggande skydd med CSP och botskydd.
4. Hantera credentials och känslig information säkert.
5. Integrera en extern betallösning i en fullstackapplikation.
6. Planera ett utvecklingsprojekt med Git och Scrum.
